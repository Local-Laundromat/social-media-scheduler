Quu API Documentation

Programmatic access for Agency tier customers

🔑 API Access: API keys are available for Agency tier ($499/mo) customers. Generate your API key in the Dashboard → Settings → API Keys section.

Authentication

All API requests require an API key passed in the header:

Authorization: Bearer YOUR_API_KEY_HERE

Base URL

https://quu.social/api

Endpoints

GET /api/posts

Get all scheduled posts

Query Parameters:

Parameter Type Description
status string Filter by status: pending, posted, failed
limit integer Number of results (default: 100)

Example Request:

curl https://quu.social/api/posts?status=pending \
  -H "Authorization: Bearer YOUR_API_KEY"

POST /api/posts

Create a new scheduled post

Request Body:

{
  "user_id": "your-user-id",
  "filename": "sunset.jpg",
  "filepath": "/path/to/sunset.jpg",
  "filetype": "image",
  "caption": "Beautiful sunset!",
  "platforms": ["facebook", "instagram"],
  "scheduled_time": "2026-05-25T18:00:00Z",
  "webhook_url": "https://your-app.com/webhook"
}

Example Request:

curl -X POST https://quu.social/api/posts \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "abc123",
    "filename": "post.jpg",
    "filepath": "/media/post.jpg",
    "caption": "Check this out!",
    "platforms": ["facebook", "instagram"],
    "scheduled_time": "2026-05-25T18:00:00Z"
  }'

POST /api/posts/:id/post-now

Immediately publish a scheduled post

Example Request:

curl -X POST https://quu.social/api/posts/123/post-now \
  -H "Authorization: Bearer YOUR_API_KEY"

DELETE /api/posts/:id

Delete a post from database and social platforms

Example Request:

curl -X DELETE https://quu.social/api/posts/123 \
  -H "Authorization: Bearer YOUR_API_KEY"

POST /api/posts/bulk-delete

Delete multiple posts at once

Request Body:

{
  "post_ids": [123, 456, 789]
}

GET /api/stats

Get dashboard statistics

Response:

{
  "stats": {
    "total": 150,
    "pending": 25,
    "posted": 120,
    "failed": 5
  }
}

Webhooks

Configure a webhook URL to receive notifications when posts are published:

{
  "event": "post.published",
  "post_id": 123,
  "status": "posted",
  "timestamp": "2026-05-21T14:30:00Z"
}

Rate Limits

Agency tier: 1000 requests/hour

Bulk operations: Up to 100 posts per request

Error Codes

Code Description
401 Invalid or missing API key
403 API access not available (upgrade to Agency tier)
404 Resource not found
429 Rate limit exceeded
500 Server error
